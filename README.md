📚 BookVault

BookVault is a full stack web application designed for book lovers to explore and manage books through a simple and attractive interface. The project allows users to browse different categories of books, add books to cart, and manage their selections easily.

🚀 Features
User Login and Signup Authentication
Multiple Book Categories
Fiction
Non-Fiction
Romance
Mystery
Sci-Fi
Add to Cart Functionality
Favorites/Wishlist Support
Responsive and User-Friendly UI
Search and Browse Books
MongoDB Database Integration
Frontend and Backend Connectivity
🛠️ Technologies Used
Frontend
HTML
CSS
JavaScript
Bootstrap
jQuery
Backend
Node.js
Express.js
Database
MongoDB Atlas
⚙️ Installation Steps
Clone the repository
git clone https://github.com/saisriya0405/Book-Vault.git
Install backend dependencies
cd backend
npm install
Start backend server
node server.js
Run frontend using Live Server or open index.html
